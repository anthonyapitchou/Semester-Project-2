# Semester Project 2 – Auction House

A front-end web application for an online auction platform, built as part of Noroff's Semester Project 2. 

Registered students (with a `@stud.noroff.no` email) can create listings, place bids using virtual credits, and manage their profile. Visitors can browse and search listings without an account.

## 🔧 Tech Stack
- TypeScript / Vanilla JavaScript
- [Tailwind ]
- [Noroff Auction House API v2](https://docs.noroff.dev/docs/v2/auction-house/listings)

## ✨ Features
- User registration & authentication (students only)
- Browse, search, and filter listings
- Create, edit, and delete listings
- Bid on listings with virtual credits
- Profile management (avatar, banner, bio)
- Responsive, accessible design
